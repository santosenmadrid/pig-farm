## 用法建议
- 稀有猪：同一张图加 CSS `filter: hue-rotate(-60deg) saturate(1.4)` 或叠一层金色，不用另画。
- 线稿是单色，背景色随便换都搭。
- 原始照片分辨率有限，显示宽度别超过 ~250px，否则会糊。
